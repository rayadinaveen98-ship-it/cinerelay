# CineRelay v0.2.2

CineRelay v0.2.2 is the first stable Phase 7 patch, introducing the Source Health & Self-Maintenance foundation while preserving the v0.2.1 Android consumer experience and update signer.

## Highlights

- Adds a service-owned source-maintenance findings ledger for operational issues that need attention.
- Separates YouTube WebSub accelerator misses from authoritative fallback health, so healthy fallback ingestion is not mislabeled as a source outage.
- Detects scheduler bookkeeping drift when stale due timestamps disagree with recent successful checks.
- Detects stale/dead sources and repeated parser failures without silently retiring or promoting trusted identities.
- Surfaces exhausted processing jobs as poison-job findings for explicit operator review.
- Produces activity-based poll-class recommendations without automatically mutating source cadence.
- Surfaces expiring WebSub subscriptions while keeping fallback polling authoritative.
- Enables RLS on the public `event_types` reference table while preserving read-only client access.
- Fixes the mutable search path warning on `record_youtube_websub_delivery`.
- Preserves the Phase 7 trust rule: automation may diagnose and propose, but high-authority trust changes remain policy/operator controlled.

## Release integrity

- Package: `com.cinerelay.app`
- Version: `0.2.2`
- Version code: `210002`
- Stable build type: Android `release` with minification and resource shrinking enabled.
- Firebase configuration is mandatory for stable publication.
- Permanent CineRelay signer is mandatory and verified against the repository-pinned certificate digest.
- Privileged server credential markers are scanned from source and the final APK before publication.

## Phase 7 status

P7.1 — Source Health & Self-Maintenance Foundation — is the first shippable Phase 7 slice. Later Phase 7 slices continue source discovery, officiality proposals, relationship suggestions, adaptive maintenance automation, and richer operator/consumer surfaces without weakening the evidence-first trust boundary.
