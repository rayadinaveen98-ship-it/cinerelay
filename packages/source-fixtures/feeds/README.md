# Feed Fixtures

Synthetic official-source fixtures used by the Phase-4 generic feed connector tests.

These fixtures cover:

- RSS 2.0 item identity, links, dates, creators, categories and HTML descriptions;
- Atom entry IDs, alternate links, published/updated dates, authors, categories and HTML summaries.

They are deterministic test data only. Real official-source canaries are added only after the connector branch passes full CI.
