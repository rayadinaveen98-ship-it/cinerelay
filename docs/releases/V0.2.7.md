# CineRelay v0.2.7 — Discovery UI refresh

An Android navigation and layout release. Official source trust, alerting, backend and catalogue facts are unchanged.

**OTT:** swipeable compact cards for This Weekend, Today, Now Streaming and Next 30 Days. Tap See all for a vertical list; tap a title for complete release details and official source.
**Radar:** Cover now, Fresh source signals and Keep watching use compact swipeable rails; See all opens the complete loaded category and each item leads to existing evidence details.
**Today in Cinema:** compact year poster rails, complete year lists and title detail view. Poster appears when supplied in existing data; otherwise year fallback. Date jumps remain intact.

Typography, horizontal gutter, card sizing and section navigation are unified by DiscoveryUiV080. Android back gesture returns from category/detail routes; landing vertical scroll position is preserved. No bottom navigation change.

QA checklist: OTT 4 full sections and source link, Radar canonical/raw opportunities, Today year/date navigation, long titles, missing artwork, system back and tab transitions. Verify on physical device; CI success alone is not interactive signoff.

The full lists include all items currently loaded by existing API calls. Backend page limits may still truncate the overall server dataset; pagination requires a separate data-contract improvement.
