# CineRelay v0.2.1

CineRelay v0.2.1 is the first stable Android promotion of the Phase 6 consumer-intelligence experience.

## Highlights

- Personalized first-run onboarding with language selection and a curated top-five official-source recommendation step, plus access to the full source directory.
- A single-card Home hero, evolving-story grouping, canonical story identity, and evidence-backed story timelines.
- Radar v2.1 with freshness decay, verification, evidence strength, source authority, corroboration, WHY NOW explanations, and action/watch hierarchy.
- Consumer-first OTT intelligence organized around This Weekend, Today, and the next 30 days, with platform/language filtering and direct evidence links.
- Today in Cinema / On This Day experience with richer historical context.
- Source-level notification controls, a global notification master, Firebase push delivery, and explicit permission/consent flows.
- Universal and intelligence search, notification detail, Sources Directory, Control Room, Settings, and personalization flows.
- Permanent Android update signer with monotonic versioning for in-place update safety.
- Evidence-first newsroom APIs and deployment-native mobile API bundles.

## Release integrity

- Package: `com.cinerelay.app`
- Version: `0.2.1`
- Version code: `210001`
- Stable build type: Android `release` with minification and resource shrinking enabled.
- Firebase configuration is mandatory for stable publication.
- Permanent CineRelay signer is mandatory and verified against the repository-pinned certificate digest.
- Privileged server credential markers are scanned from source and the final APK before publication.

## Known follow-up

The consumer UX has extensive CI coverage and update-signing has existing physical-device proof. The current V0.2 consumer screens should continue receiving real-device visual QA and polish in the next patch line; that follow-up does not alter the evidence-first or update-safe release contract.
