# CineRelay v0.2.3

CineRelay v0.2.3 advances the Phase 7 source-maintenance work and refreshes the Android first-launch experience while preserving the permanent update signer, Firebase requirement, evidence-first ingestion rules, and dormant X connector.

## Highlights

- Replaces the older multicolour Android welcome with a lightweight cinema-signal sequence built directly in Compose.
- Shows the welcome once per installed app version and honors the system remove-animations preference.
- Continues Phase 7 source discovery, officiality review, explicit identity attachment, source/entity relationship suggestions, and maintenance visibility without silently changing trusted authority.
- Adds the remaining explicitly approved official/high-confidence YouTube source gaps for Sun TV, Ayngaran, Saina Movies, Muzik247, Anand Audio, DBeatsMusicWorld, and Saregama Music.
- Reuses the existing YouTube WebSub accelerator plus authoritative fallback path for the new YouTube identities.
- Adds ManoramaMAX as an approved Tier-1 OTT provider while keeping its first-party web identity inactive until a parser profile is explicitly verified.
- Preserves existing approved coverage for Geetha Arts, Aditya Music, YRF, Dharma Productions, Aha, Sun NXT, ZEE5, JioHotstar, and Sony LIV without duplicating them.
- Keeps the X connector dormant; v0.2.3 does not reactivate X polling or spend.

## Release integrity

- Package: `com.cinerelay.app`
- Version: `0.2.3`
- Version code: `210003`
- Stable build type: Android `release` with minification and resource shrinking enabled.
- Firebase configuration is mandatory for stable publication.
- Permanent CineRelay signer is mandatory and verified against the repository-pinned certificate digest.
- Privileged server credential markers are scanned from source and the final APK before publication.
- v0.2.2 remains immutable.

## Trust and ingestion boundaries

- Automation may discover, diagnose, and propose; it does not silently promote high-authority sources or relationships.
- The approved YouTube additions use canonical channel IDs and the existing trusted registration path.
- ManoramaMAX is registry-visible but its web connector stays inactive until parser-profile verification.
- WebSub remains an accelerator; fallback ingestion remains authoritative.
- X remains intentionally dormant behind the existing provider-payment gate.
